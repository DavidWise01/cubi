# CUBI — Tensor cubit Persistent Memory

Canonical expression: `{{ T || {} || [] || () || /\\ || \\/ || }}`

This repository contains an interactive, standalone GitHub Pages app with 9 neon cubit spheres (LH/CH/RH × short/medium/long memory tiers), original memory records, inherited references, provenance inspection, independent agent cycles, and visible event logs.

## Use

Open https://davidwise01.github.io/cubi/ once Pages is enabled. Type an observation, choose a compartment and a matching origin (LH ff/fr, CH cf/cr, RH rf/rr), and press Remember. Agent Cycle promotes references through L0→L1→L2; Start Agent repeats cycles while the tab is active. Click a sphere to inspect ancestry. Export JSON for a portable backup.

## Operators

`.` = toroid, `|` = BOX, `..||..|` = nested scaffold, `[(([[(())]]))]` = requested visual containment motif.

## Persistence boundaries

The local browser stores original memories, shadows and process observations in one SHA-256-checked JSON checkpoint. It is not a hosted database, cryptographic authentication, independently anchored chain, or synchronized multi-device service. Deleting site storage deletes local memory; export backups regularly. This model uses the literal theoretical `cubit` symbol and does not implement a hardware qubit.
