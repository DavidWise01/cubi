# Kernel 135 — Pinned 000 Walker

Open `index.html` in Chromium. The walker starts at `000` and follows OUT, LEFT, RIGHT, UP, DOWN, HOME. A user-adjustable model gravity bends each route; endpoints are held fixed, returning to `000` exactly by construction. The route repeats.

Each leg is marked `24!` (620448401733239439360000) as a symbolic traversal budget. It is visualized by 24 microsteps per leg, not by factorial enumeration. Existing Kernel 134 lattice-guided flow, 366 colored registry, 120-degree vectors and fading gray pixel wash are preserved.

Exploratory animation: not a physical gravity simulation or empirical scientific result.
