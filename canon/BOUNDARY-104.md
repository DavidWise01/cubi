# CUBI 104 — Global diodic field and layer-one ceiling

Canonical user expression, preserved verbatim: `{{n}}^{{n}}x1.61658^10`.

The expression denotes the **symbolic upper ceiling of the layer-one floor** in CUBI. It is not automatically equivalent to Planck length (whose usual length-scale notation has a negative power of ten) and it is not interpreted as a measured physical distance. Its `n` is unbound; no finite numeric cap is invented.

All model mutations are governed conceptually by one-way evidence: past events may be observed but not rewritten. A new global append-only browser journal records the neural stimulus, resets, and Gap C events with sequence numbers, predecessor references, ten-phase C1/C2/C3 recurrence, model tick and the exact canonical floor expression. A mismatched history invokes GLOBAL DIODIC HOLD for operations guarded by this journal.

The existing persistent memory checkpoint and bounded history are preserved, and a new Audit floor ceiling button exposes the global event register. Importantly, this version does **not** yet merge all browser-local stores into one atomic transaction; neural state ticks and manually changed slider settings are not individually appended, so complete global diodicity is still a design invariant rather than a proven implementation guarantee. The journal is not cryptographically anchored and can be externally modified through browser storage. No quorum.
