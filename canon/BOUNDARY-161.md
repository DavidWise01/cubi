# CUBI 161 — Scalar-0 Field Curvature Band Test

User design: magnetic scalar 0, with proposed bands weak=9, medium=6, strong=3, fission=1. The direction of increasing curvature toward zero is tested for the *chosen* mathematical law kappa(r)=1/r at radii 9,6,3,1. Results: 1/9, 1/6, 1/3, 1; all four increase monotonically as r decreases. Mathematical PASS means only consistency with this model law. It is not an independent derivation of magnetic field-line curvature.

The center r=0 is singular and assigned BOUNDARY, not a finite verified field state. Physical mapping of weak/strong nuclear forces to these radii is UNVERIFIED; `medium force` is not a conventional fundamental interaction and fission is a nuclear process, not a fundamental force. Magnetic field strength (sometimes varying as 1/r^3 for a dipole in appropriate regimes) is not itself field-line curvature. A Maxwell-field geometry and empirical calibration would be needed before claiming physical validation.

An interactive test lives in `curvature161.js` and runs on the GitHub Page. No new Lean. No quorum. Live browser execution not independently verified.
