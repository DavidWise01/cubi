# CUBI 100 — Neural feedback inheritance

The active cortex can retrieve its most recently bound Gap C observation from the existing CH.L0 SHA-256-checked browser checkpoint via a read-only bridge. The latest current Gap C sample is compared against this original historical observation.

A bounded model-only proportional proposal is computed from delta change (current Gap A-minus-B contribution minus previous delta). A and B adjustment magnitudes are capped at 0.05 per proposed step, and slider values are clamped to [0,1]. The user may explicitly apply or decline the proposal; no agent automatically rewrites settings. The original saved memory remains untouched. After application, subsequent ticks use the new sliders and Gap C can observe the result.

Controls: Compare recalled WHY; Apply bounded adjustment. Missing prior memory, missing current event or nonfinite measurements produce HOLD.

This is an exploratory feedback rule, not a calibrated control system or verified physiological explanation. No claim of optimizing a biological brain. No external service, no quorum. Neural working state remains ephemeral; the original stored Gap C observation retains its append-only memory identity. GitHub Pages live execution is not independently verified.
