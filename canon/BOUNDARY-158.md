# CUBI 158 — 118-Element Occupancy Baseline

Goal: extend CUBI157 H–Ne to H–Og (Z=1..118) using nominal Aufbau filling and Pauli-unique state labels (n,l,m,spin). Every element Z has exactly Z occupied labels and no repeated complete state label.

The 24 toroidal positions derive from user-proposed 8 sectors × 3 positions; this is **not a derivation** of 118 distinct quantum states or nuclear charge. A winding/topology-to-quantum-number mapping remains unproved. Element symbols and an 118-element selector are integrated into GitHub Pages via `chemistry158.js`.

The ordinary n+l Aufbau filling order is a simplified baseline. Known departures (e.g., Cr, Cu and many d/f block systems), relativistic heavy-element behavior, Hund ordering and electron correlations mean outputs must not be represented as experimentally accurate ground-state configurations for all 118 elements; especially Og is strongly relativistic and incompletely characterized experimentally. Flags identify illustrative exceptions but are not exhaustive. No claim that Wheeler's one-electron hypothesis reproduces physical multi-electron occupancy. Browser test execution is unverified.

No additional Lean proofs. No quorum. No original history mutation.
